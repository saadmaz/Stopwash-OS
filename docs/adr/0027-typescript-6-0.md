# ADR-0027: TypeScript 6.0

| Status | Date |
| --- | --- |
| Accepted | 2026-11-15 |

## Decision

Pin `typescript ~6.0.3`. TS 7 (native compiler) is out, but typescript-eslint 8.x supports `<6.1`. Revisit when typescript-eslint supports 7.

## Alternatives considered

None recorded.

Not recorded.
