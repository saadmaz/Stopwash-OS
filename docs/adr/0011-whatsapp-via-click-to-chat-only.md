# ADR-0011: WhatsApp via click-to-chat only

| Status | Date |
| --- | --- |
| Accepted | 2026-11-15 |

## Decision

`https://wa.me/{number}?text=…` links built from settings (`notificationNumbers`). No paid API, and no number in code.

## Alternatives considered

None recorded.

## Rationale

Keeps parity, costs nothing, and the number is configurable.
