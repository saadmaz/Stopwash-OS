## Decision

`payroll.attendanceMultiplier.enabled = false` reproduces 2.5 behaviour. When enabled: PRESENT 1.0, LATE 1.0, HALF_DAY 0.5, ABSENT 0, LEAVE 0 (configurable).

None recorded.
